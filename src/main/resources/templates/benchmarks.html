为什么有的榜单全是海外模型、有的全是国产模型？

这里聚合的榜单分属两类不同的参赛池（卡片标题旁有类别标签），并非按国籍筛选：

  • 竞技场（DeepSWE / Terminal-Bench）：闭源 API 模型报名参赛，海外厂商（OpenAI / Anthropic / Google）的 API 生态更成熟，因此清一色海外模型；
